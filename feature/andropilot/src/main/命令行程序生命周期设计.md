# AndroMosaic CLI 程序生命周期设计

## 概述

AndroMosaic 是一个基于 Kotlin + JVM 的声明式 UI 命令行程序，使用 Mosaic 库构建交互式界面。该程序作为 Android CLI 的可视化前端，通过声明式 UI 管理程序的各个生命周期阶段。

## 详细状态描述

### 1. **MENU_SELECTION_STATE** - 主菜单选择状态

**目的**: 展示 Android CLI 的所有顶级命令模块，让用户选择要进行的操作类别。

**UI 布局**:
```
╔════════════════════════════════════════════╗
║        AndroMosaic - Android CLI 可视化    ║
╠════════════════════════════════════════════╣
║                                            ║
║  请选择命令模块 (使用↑↓导航，Enter确认)   ║
║                                            ║
║  ▶ create      - 项目创建和模板管理        ║
║    describe    - 项目分析和元数据获取      ║
║    emulator    - 虚拟设备管理             ║
║    sdk        - SDK 包管理                ║
║    skills     - Android 技能管理          ║
║    screen     - 屏幕截图和交互           ║
║    run        - 应用部署和运行            ║
║    docs       - 知识库搜索和文档获取      ║
║    info       - 环境信息查询              ║
║    update     - CLI 和 SDK 更新           ║
║                                            ║
║  [q] 退出程序                             ║
╚════════════════════════════════════════════╝
```

**状态转移**:
- 用户选择某个模块 → **COMMAND_LIST_STATE**
- 用户按 `q` 退出 → **Application Exit**
- 用户按 Esc 或返回 → 保持当前状态

**关键操作**:
- 上/下箭头导航
- Enter 确认选择
- 高亮显示当前选项

---

### 2. **COMMAND_LIST_STATE** - 命令列表显示状态

**目的**: 展示选定模块下的所有具体命令和子命令，让用户选择要执行的命令。

**例如选择 `create` 模块时的 UI**:
```
╔════════════════════════════════════════════╗
║  模块: create - 项目创建和模板管理        ║
╠════════════════════════════════════════════╣
║                                            ║
║  请选择命令 (使用↑↓导航，Enter确认)      ║
║                                            ║
║  ▶ create              从模板初始化新项目  ║
║    create list         列出可用模板       ║
║                                            ║
║  命令说明:                                 ║
║  初始化一个新的 Android 项目。可选模板，  ║
║  支持干运行和详细输出选项。               ║
║                                            ║
║  [b] 返回主菜单  [q] 退出程序            ║
╚════════════════════════════════════════════╝
```

**状态转移**:
- 用户选择命令 → 检查是否需要参数
  - 需要参数 → **PARAMETER_INPUT_STATE**
  - 不需要参数 → **COMMAND_EXECUTION_STATE**
- 用户按 `b` 返回 → **MENU_SELECTION_STATE**
- 用户按 `q` 退出 → **Application Exit**

**关键操作**:
- 命令导航和选择
- 实时显示选中命令的帮助信息
- 支持命令搜索（可选）

### 3. **PARAMETER_INPUT_STATE** - 参数输入状态

**目的**: 为需要参数的命令收集用户输入，提供交互式表单填充或选项设置。

**例如 `create` 命令的参数输入**:
```
╔════════════════════════════════════════════╗
║  命令: create - 从模板初始化新项目        ║
╠════════════════════════════════════════════╣
║                                            ║
║  必填参数:                                 ║
║  ├─ 输出目录 (--output):  [_____________] ║
║                                            ║
║  可选参数:                                 ║
║  ├─ 项目名称 (--name):     [_____________] ║
║  ├─ 模板选择 (template):   [empty-activity] ║
║  ├─ 干运行 (--dry-run):    [ ] 启用       ║
║  ├─ 详细输出 (--verbose):  [ ] 启用       ║
║                                            ║
║  提示: 模板列表可通过 "create list" 命令  ║
║        查看所有可用选项。                  ║
║                                            ║
║  [c] 取消  [r] 重置  [e] 执行命令        ║
╚════════════════════════════════════════════╝
```

**状态转移**:
- 用户完成参数输入 → **COMMAND_EXECUTION_STATE**
- 用户按 `c` 取消 → **COMMAND_LIST_STATE**
- 用户按 `r` 重置 → 清空所有输入，保持当前状态

**关键操作**:
- 文本输入框
- 下拉选择菜单
- 复选框
- 参数验证和提示

### 4. **COMMAND_EXECUTION_STATE** - 命令执行状态

**目的**: 执行构建好的 Android CLI 命令，通过 ProcessBuilder 启动进程并实时显示执行进度。

**UI 显示**:
```
╔════════════════════════════════════════════╗
║  正在执行: create --output=/path/to/proj  ║
╠════════════════════════════════════════════╣
║                                            ║
║  [████████████░░░░░] 45% 已完成           ║
║                                            ║
║  执行日志:                                 ║
║  > 初始化项目结构...                      ║
║  > 从模板复制文件...                      ║
║  > 配置 build.gradle...                   ║
║  ⏳ 等待 SDK 工具初始化...               ║
║                                            ║
║  实时输出:                                 ║
║  $ android create --output=/path/to/proj  ║
║  Initializing project template...         ║
║                                            ║
║  [C] 停止执行                             ║
╚════════════════════════════════════════════╝
```

**状态转移**:
- 命令执行成功 (exit code = 0) → **RESULT_DISPLAY_STATE**
- 命令执行失败 (exit code ≠ 0) → **ERROR_DISPLAY_STATE**
- 超时或被中断 → **TIMEOUT_STATE**

**关键操作**:
- ProcessBuilder 进程管理
- 实时标准输出/错误流读取
- 进度动画显示
- 支持中断（Ctrl+C）

### 5c. **TIMEOUT_STATE** - 超时状态

**目的**: 处理命令执行超时或被用户中断的情况，提供重试或取消选项。

**UI 显示**:
```
╔════════════════════════════════════════════╗
║  执行结果: emulator start ⏱ 超时           ║

║                                            ║
║  可能原因:                                 ║
║  1. Android 模拟器启动缓慢                ║
║  2. 网络连接问题导致 SDK 下载缓慢        ║
║  3. 系统资源不足                          ║
║  4. 虚拟设备配置问题                      ║
║                                            ║
║  执行日志:                                 ║
║  $ android emulator start medium_phone    ║
║  Waiting for device boot...               ║
║  Checking device status...                ║
║  ⏳ (Process killed after 5 minutes)     ║
║                                            ║
║  可选操作:                                 ║
║  [r] 重新执行              [o] 调整超时时间  ║
║  [v] 返回查看虚拟设备列表  [m] 返回菜单    ║
║  [q] 退出程序                             ║
╚════════════════════════════════════════════╝
```

**状态转移**:
- 用户选择 `[r]` → **COMMAND_EXECUTION_STATE**（重新执行相同命令）
- 用户选择 `[o]` → **PARAMETER_INPUT_STATE**（调整参数后重试）
- 用户选择返回上一级 → 对应的前置状态
- 用户选择 `[q]` → **Application Exit**

**关键操作**:
- 超时检测和处理
- 可配置的超时时间
- 进程强制终止（如必要）

### 6. **ACTION_MENU_STATE** - 操作菜单状态

**目的**: 提供执行结果后的后续操作选项，让用户决定接下来的动作。

**UI 显示**:
```
╔════════════════════════════════════════════╗
║  后续操作菜单                             ║
╠════════════════════════════════════════════╣
║                                            ║
║  请选择操作:                               ║
║                                            ║
║  ▶ 执行另一条命令     返回当前命令模块   ║
║    返回主菜单          返回命令选择界面   ║
║    查看完整日志        打开日志详情窗口   ║
║    复制结果            将结果复制到剪贴板 ║
║    保存结果            将结果保存为文件   ║
║    退出程序            关闭 AndroMosaic   ║
║                                            ║
║  [↑↓] 导航  [Enter] 确认  [q] 退出      ║
╚════════════════════════════════════════════╝
```

**状态转移**:
- 执行另一条命令 → **COMMAND_LIST_STATE**（返回当前模块的命令列表）
- 返回主菜单 → **MENU_SELECTION_STATE**
- 查看完整日志 → 弹出日志窗口，保持当前状态
- 复制结果 → 复制操作完成，弹出成功提示，保持当前状态
- 保存结果 → 打开文件保存对话框，完成后保持当前状态
- 退出程序 → **Application Exit**

**关键操作**:
- 多选项菜单导航
- 结果剪贴板复制
- 文件保存

## 状态转移表

| 当前状态              | 触发条件             | 目标状态                           | 备注        |
|-------------------|------------------|--------------------------------|-----------|
| MENU_SELECTION    | 选择模块             | COMMAND_LIST                   | 进入选定的命令模块 |
| MENU_SELECTION    | 按 q              | Application Exit               | 退出程序      |
| COMMAND_LIST      | 选择无参数命令          | COMMAND_EXECUTION              | 直接执行      |
| COMMAND_LIST      | 选择需参数命令          | PARAMETER_INPUT                | 先输入参数     |
| COMMAND_LIST      | 按 b              | MENU_SELECTION                 | 返回主菜单     |
| COMMAND_LIST      | 按 q              | Application Exit               | 退出程序      |
| PARAMETER_INPUT   | 点击执行             | COMMAND_EXECUTION              | 带参数执行命令   |
| PARAMETER_INPUT   | 按 c              | COMMAND_LIST                   | 取消参数输入    |
| PARAMETER_INPUT   | 按 r              | PARAMETER_INPUT                | 重置表单      |
| COMMAND_EXECUTION | 成功完成             | RESULT_DISPLAY                 | 显示执行结果    |
| COMMAND_EXECUTION | 失败 (非零exit code) | ERROR_DISPLAY                  | 显示错误信息    |
| COMMAND_EXECUTION | 超时/中断            | TIMEOUT                        | 显示超时提示    |
| RESULT_DISPLAY    | 按 m              | ACTION_MENU                    | 进入操作菜单    |
| RESULT_DISPLAY    | 按 q              | Application Exit               | 退出程序      |
| ERROR_DISPLAY     | 按 r              | COMMAND_LIST 或 PARAMETER_INPUT | 重试命令      |
| ERROR_DISPLAY     | 按 m              | ACTION_MENU                    | 进入操作菜单    |
| TIMEOUT           | 按 r              | COMMAND_EXECUTION              | 重新执行      |
| TIMEOUT           | 按 o              | PARAMETER_INPUT                | 调整参数后重试   |
| TIMEOUT           | 按 m              | ACTION_MENU                    | 进入操作菜单    |
| ACTION_MENU       | 执行另一条命令          | COMMAND_LIST                   | 回到当前模块    |
| ACTION_MENU       | 返回主菜单            | MENU_SELECTION                 | 返回主菜单     |
| ACTION_MENU       | 退出程序             | Application Exit               | 关闭程序      |

---

## 核心交互流程

### 流程 1: 简单命令执行 (无参数)
```
MENU_SELECTION → COMMAND_LIST → COMMAND_EXECUTION 
→ RESULT_DISPLAY → ACTION_MENU → (返回主菜单或退出)
```

### 流程 2: 参数化命令执行
```
MENU_SELECTION → COMMAND_LIST → PARAMETER_INPUT 
→ COMMAND_EXECUTION → RESULT_DISPLAY → ACTION_MENU
```

### 流程 3: 错误恢复流程
```
COMMAND_EXECUTION → ERROR_DISPLAY → PARAMETER_INPUT 
→ COMMAND_EXECUTION → RESULT_DISPLAY
```

### 流程 4: 超时重试流程
```
COMMAND_EXECUTION → TIMEOUT → (重试或返回菜单)
```

## 状态机实现建议

### 1. **State 接口或枚举**
```kotlin
sealed class AppState {
    data object MenuSelection : AppState()
    data class CommandList(val moduleId: String) : AppState()
    data class ParameterInput(val command: Command) : AppState()
    data class CommandExecution(val command: String) : AppState()
    data class ResultDisplay(val result: CommandResult) : AppState()
    data class ErrorDisplay(val error: CommandError) : AppState()
    data class TimeoutState(val command: String) : AppState()
    data class ActionMenu(val previousResult: CommandResult) : AppState()
}
```

### 2. **事件处理**
```kotlin
sealed class UserEvent {
    object KeyUp : UserEvent()
    object KeyDown : UserEvent()
    object KeyEnter : UserEvent()
    object KeyEscape : UserEvent()
    data class TextInput(val text: String) : UserEvent()
}
```

### 3. **状态管理**
使用 Mosaic 的状态管理和响应式 UI 来驱动状态转移：
- 每个状态对应一个 Composable 函数
- 使用 `LaunchedEffect` 处理副作用（如进程执行）
- 通过 `remember` 维护当前状态
